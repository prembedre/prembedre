## About

I'm a technology enthusiast interested in building practical software and exploring how technology can solve real-world problems.

My interests sit at the intersection of **software development, cybersecurity, data analytics and AI**. I enjoy working across the stack, experimenting with tools, and turning ideas into useful applications.

- 🔐 **Security:** Log analysis, basic network defense, vulnerability assessment and incident response concepts.
- 📊 **Data:** SQL, Power BI and data-driven reporting.
- 🧠 **AI & intelligent systems:** Generative AI, NLP and explainable AI.
- 🛠️ **Development:** Web applications, APIs, mobile apps and backend integration.
